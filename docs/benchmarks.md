# Benchmark 证据卡

[返回首页](../README.md) · [中文导读](../README.zh-CN.md)

资料快照：2026-10-28。来自前期调研记录；未独立复跑。本页由 `data/catalog.json` 生成，规模与定义按所链接来源解释。

## 1. LoCoMo

**类别**：历史与事实 · **阅读定位**：对照 · **时间标记**：2024

- 任务：跨会话事实、多跳、时间推理；原始任务还包括事件总结和多模态对话生成。

- 规模：官方 locomo10：10 段长对话；常见 QA 评测为 1,540 个非 adversarial 问题。

- 指标：原始 QA 的文本匹配指标与后续 LLM judge accuracy 必须分列。

- 限制：对话数量少；只报四类 QA 不等于完成原始全部任务。

- 来源：[原始来源](https://github.com/snap-research/locomo)

## 2. LongMemEval

**类别**：历史与事实 · **阅读定位**：核心 · **时间标记**：2024 / ICLR 2025

- 任务：信息抽取、跨会话推理、时间推理、知识更新、拒答。

- 规模：500 个问题；常用 S 约 115k tokens，M 为更长历史；S/M/oracle 分开。

- 指标：官方按题型设计的 LLM judge；同时报告逐题总体准确率及各类结果。

- 限制：检索证据 Recall@k 与最终 QA accuracy 是不同指标；也不是完整个人行动测试。

- 来源：[原始来源](https://arxiv.org/abs/2410.10813) · [Code](https://github.com/xiaowu0162/LongMemEval)（Official benchmark repository. 链接核对：2026-10-28；未执行或审计代码。）

## 3. BEAM

**类别**：历史与事实 · **阅读定位**：扩展 · **时间标记**：2025 / 2026

- 任务：极长且连贯的对话中的多类记忆能力。

- 规模：100 段对话、2,000 个验证问题，最长 10M tokens。

- 指标：按长度档位和能力分别报告回答分数。

- 限制：合成对话；不要把 100k 与 10M 的结果合并排名。原论文方法为 LIGHT。

- 来源：[原始来源](https://arxiv.org/abs/2510.27246)

## 4. ConvoMem

**类别**：历史与事实 · **阅读定位**：扩展 · **时间标记**：2025

- 任务：个人事实、助手信息、拒答、偏好、时间变化与隐式联系。

- 规模：75,336 个 QA，适合分析历史规模变化。

- 指标：回答质量 + 成本 + 延迟。

- 限制：很适合检验 full context 与检索的转折点；论文中的小历史结论有模型与规模条件。

- 来源：[原始来源](https://arxiv.org/abs/2511.10523)

## 5. PrefEval

**类别**：偏好与个性化 · **阅读定位**：核心补充 · **时间标记**：2025

- 任务：显式 / 隐式偏好的推断、记忆和主动遵循。

- 规模：3,000 个 preference-query pairs、20 个主题；最长约 100k tokens。

- 指标：分类任务正确率、生成任务偏好遵循。

- 限制：聚焦 preference following；与复杂动态用户画像和实际工具执行互补。

- 来源：[原始来源](https://arxiv.org/abs/2502.09597)

## 6. PersonaMem v1

**类别**：偏好与个性化 · **阅读定位**：历史对照 · **时间标记**：2025

- 任务：随时间演化的画像和偏好；选择符合当前用户状态的回复。

- 规模：180+ 模拟历史、每段最多 60 sessions、15 类任务。

- 指标：个性化回复选择准确率。

- 限制：v1 和 v2 不是同一数据集；不能省略版本。

- 来源：[原始来源](https://arxiv.org/abs/2504.14225) · [Code](https://github.com/bowen-upenn/PersonaMem)（Official v1 repository; do not assume it implements all v2 settings. 链接核对：2026-10-28；未执行或审计代码。）

## 7. PersonaMem-v2

**类别**：偏好与个性化 · **阅读定位**：核心 · **时间标记**：2025

- 任务：从自然任务对话推断隐式偏好，含动态变化、归属辨别与遗忘请求。

- 规模：1,000 personas；20,000+ 偏好；32k / 128k；benchmark 5,000 QA。

- 指标：MCQ accuracy 与 open-ended judge 分开报告。

- 限制：合成个人历史；32k→2k 的 token 压缩率不等于全生命周期计算降本 16 倍。

- 来源：[原始来源](https://arxiv.org/html/2512.06688v1)

## 8. PersonaMem-v3

**类别**：跨平台与行动 · **阅读定位**：前沿扩展 · **时间标记**：2026

- 任务：跨平台画像、推荐、过度个性化、agentic tasks 与主动介入时机。

- 规模：以真实互动信号构建时间化的多平台用户世界；提供代码和数据链接。

- 指标：按任务家族报告；同时衡量应行动与应保持沉默的场景。

- 限制：真实信号支撑的构造环境，不等于长期真实用户部署；本次核到论文版本及资源链接。

- 来源：[原始来源](https://arxiv.org/html/2608.21381v1)

## 9. Mem2ActBench

**类别**：跨平台与行动 · **阅读定位**：核心 · **时间标记**：2026

- 任务：把历史偏好和任务状态用于工具参数补全。

- 规模：2,029 sessions、400 tool-use tasks；主实验筛选了 429 个证据会话。

- 指标：参数 F1、BLEU-1，另有工具指标；主表给定 gold tool。

- 限制：主表不是自由选工具的完整端到端任务成功率；TA 定义与表中数值关系需再核代码。

- 来源：[原始来源](https://arxiv.org/html/2601.19935v1) · [Code & data](https://github.com/Cantaloupe-M/Mem2ActBench)（Official benchmark repository. 链接核对：2026-10-28；未执行或审计代码。）

## 10. LifeBench

**类别**：跨平台与行动 · **阅读定位**：多源扩展 · **时间标记**：2026

- 任务：跨长期数字痕迹整合事实、经历、习惯与程序性线索。

- 规模：长周期多源生活模拟；真实先验约束合成。

- 指标：长期、多源证据问答。

- 限制：此处为 arXiv:2603.03781；不要与 DeepMind Life-Bench 或长度遵循 LIFEBench 混淆。

- 来源：[原始来源](https://arxiv.org/abs/2603.03781)

## 11. MemoryCD

**类别**：偏好与个性化 · **阅读定位**：推荐扩展 · **时间标记**：2026

- 任务：跨领域评分预测、物品排序、评论总结和评论生成。

- 规模：Amazon 真实历史行为；12 个领域、4 类任务。

- 指标：评分 / 排序 / 文本生成各自指标，不能揉成 QA accuracy。

- 限制：适合个性化推荐与风格迁移，不直接测工具执行。

- 来源：[原始来源](https://arxiv.org/html/2603.25973v1)

## 12. KnowMe-Bench

**类别**：偏好与个性化 · **阅读定位**：理解扩展 · **时间标记**：2026

- 任务：基于自传叙事，测事实、主观状态与原则层面的个人理解。

- 规模：长篇叙事重建成含时间锚点的证据流。

- 指标：分层问题和证据支撑的理解质量。

- 限制：叙事人物与对话用户存在分布差异；适合陪伴 / 深层理解方向。

- 来源：[原始来源](https://arxiv.org/abs/2601.04745)

## 13. MemoryAgentBench

**类别**：机制与边界 · **阅读定位**：诊断 · **时间标记**：2025 / 2026

- 任务：增量输入下的准确检索、测试时学习、长程理解、选择性遗忘。

- 规模：统一多轮接口，含改编任务和新构造任务。

- 指标：按各任务原生指标分别报告。

- 限制：通用记忆能力诊断；不能单凭总分声称 Personal 场景有效。

- 来源：[原始来源](https://arxiv.org/abs/2507.05257)

## 14. LaMP / LongLaMP

**类别**：机制与边界 · **阅读定位**：生成补充 · **时间标记**：2023–2024

- 任务：基于用户历史的个性化分类与生成；LongLaMP 扩展到长文本。

- 规模：LaMP 为 3 类分类 + 4 类生成任务。

- 指标：分类 / 生成任务指标与个性化质量。

- 限制：适合作为 personalized generation 对照，非完整动态记忆生命周期 benchmark。

- 来源：[原始来源](https://arxiv.org/abs/2304.11406) · [第二来源](https://arxiv.org/abs/2407.11016)

## 15. LongMemEval-V2

**类别**：机制与边界 · **阅读定位**：场景外邻接 · **时间标记**：2026

- 任务：Web agent 对环境状态、流程、陷阱和前提的经验记忆。

- 规模：451 个人工整理的问题、五类能力。

- 指标：环境经验相关回答质量。

- 限制：重点是 experienced colleague 的环境经验，不能当作原版 Personal chat memory 的简单升级替代。

- 来源：[原始来源](https://arxiv.org/abs/2605.12493) · [Code](https://github.com/xiaowu0162/LongMemEval-V2)（Official environment-experience benchmark repository. 链接核对：2026-10-28；未执行或审计代码。）
